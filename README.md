🍣 Interactive Kura Sushi Menu Catalog

A dynamic, data-driven restaurant menu web application inspired by the operational and customer experience systems at Kura Sushi USA.

This project was originally built as part of a technical assessment for Snap Engineering Academy Summer 2026 and later expanded into a personal portfolio piece demonstrating frontend development, data manipulation, and UI design skills.

This repository is a further development based on a prior project assessment. To view commit history for the original project submission, please go to this repository: https://github.com/myatthitkoko/SEA2026-mtkk

📌 Features

🔍 Search Functionality
Search menu items by name, type, price, or ingredients

🔃 Sorting System
Sort items alphabetically or by price (high → low / low → high)

🍱 Category Filtering
Filter menu by item type (Nigiri, Rolls, Sides, Ramen, Desserts)

⚠️ Allergen Filtering
Remove items containing allergens such as dairy or shellfish

🎡 Animated Conveyor Belt UI
Inspired by rotating sushi belt dining systems

📱 Responsive Design
Optimized for desktop and mobile viewing

🧩 Project Motivation

This project was inspired by my experience working in a technology-driven restaurant environment at Kura Sushi. While interacting with guests and assisting them with digital ordering systems, I noticed the need for a faster, more intuitive way to explore menu items and allergen information.

This application simulates that idea by allowing users to:

Quickly search and filter menu items
View structured ingredient data
Interact with a dynamic UI similar to a digital ordering system

🧪 What I Learned
How to structure and manipulate complex data in JavaScript
How to build interactive UI components without frameworks
How to implement filtering, sorting, and search logic
How DOM updates impact performance and structure
How to design user-friendly interfaces for real-world use cases
